# Рабочая тетрадь №1. Проверка практической работы

**Про вариант.** В трёх файлах тетради нет ни слова про варианты или индивидуальные данные: все 10 практических заданий общие для всех
(8-е со звёздочкой — самостоятельное). «10-й вариант» в тетради не предусмотрен. Если вариант выдаёт преподаватель,
уточните у него, например, не отдельное ли это задание №10. Задание №10 — про экспорт с заданной структурой (см. ниже).

## Как открыть и запустить

1. Запустите Loginom, «Открыть пакет…» → выберите `.lgp` из этой папки (данные лежат рядом, пути относительные).
2. Двойной щелчок по узлу открывает мастер настройки. Правый щелчок по порту → «Быстрый просмотр» показывает данные.
3. Чтобы всё посчитать, выберите узел → «Выполнить» (или нажмите «Выполнить всё»).
4. Если узел красный, откройте журнал или «Технические подробности» и сверьтесь с разделом «Что проверить» в `README.md`.

**Важно:** пакеты сгенерированы программно. Открывались они у меня без ошибок, но ни один узел не выполнялся. Ожидаемые результаты ниже
посчитаны отдельно (pandas); для задания 8 они совпали с вашим `вывод.txt`, полученным в Loginom, для части 1 — с началом вашего `result_electro.lgd`.

## Задания 6–7. Пакет `Рабочая_тетрадь_1_часть_2_задания_6-7.lgp`

| | |
|---|---|
| Требовалось | Открыть `Продажи по чекам.lgd`, в Калькуляторе создать поля: текущая дата, сумма (промежуточное), накопительная сумма (с флагом «Кэшировать»), статус по порогу 20 000; изучить деление на ноль |
| Сделано | **Loginom Data файл** → **Калькулятор** с выражениями по порядку: `CurrentDate = Today()`; `Amount = COST * CNT` (промежуточное, в выход не попадает); `CumAmount = CumulativeSum("Amount")`; `Status = IF(Amount > 20000, "001", "002")` (строка); `DivZero = COST / 0` |
| Как работает | Для каждой строки считается сумма как цена × количество; накопительная сумма растёт по строкам; статус «001» ставится при сумме больше 20 000, иначе «002». `COST / 0` даёт бесконечность — так тетрадь показывает, почему стоит применять `IFF()` |
| Проверка | В выходной таблице должны быть поля Текущая дата, Накопительная сумма, Статус, Деление на ноль, но **не должно быть** поля Сумма. Статусы только «001» и «002». **Если калькулятор не видит `COST`/`CNT`**, замените имя на то, что видно в списке полей: имя `COST` я выбрал по догадке |
